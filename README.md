# Küchentisch MTG

Virtueller Magic-Spieltisch zum Spielen mit Freunden im Browser: Decks laden (Kartenbilder von Scryfall), Tisch per Code teilen, 2 Spieler oder Commander zu viert, KI-Gegner zum Testen.

Spielen: über den GitHub-Pages-Link dieses Repositorys.

Updates: `index.html` und `version.json` ersetzen. Offene Tische prüfen `version.json` regelmässig und laden sich bei einer neuen Version selbst neu.
